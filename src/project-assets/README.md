# Modelos específicos do projeto

Coloque nesta pasta os modelos autorizados do cenário, veículo e personagem em `.fbx`, `.glb`, `.gltf` ou `.obj` e registre cada item em `catalog.json`.

Exemplo:

```json
{
  "id": "veiculo-principal",
  "name": "Veículo principal",
  "type": "vehicle",
  "file": "./src/project-assets/veiculo-principal.fbx",
  "license": "Arquivo próprio / autorizado",
  "creator": "Nome do criador",
  "attribution": "Crédito que deve acompanhar o modelo",
  "source": "https://exemplo.com/fonte"
}
```

Os arquivos citados como anexados não estavam disponíveis na conversa usada para preparar esta versão, portanto o catálogo foi deixado pronto para recebê-los sem inventar autoria ou licença.
